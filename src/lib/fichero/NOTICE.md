# Provenance

Le contenu de ce dossier est le client Web Bluetooth de la **Fichero D11s** issu de
[`0xmh/fichero-printer`](https://github.com/0xmh/fichero-printer), sous licence MIT
(déclarée dans son README). Ce client est lui-même porté de la bibliothèque
[niimbluelib](https://github.com/MultiMote/niimbluelib) du projet
[NiimBlue](https://github.com/MultiMote/niimblue) de MultiMote, sous licence MIT.

Il est copié tel quel, sans dépendance, pour que Barda n'ait rien à installer de plus.
Seul le point d'entrée de Barda l'utilise : `src/lib/printers/fichero-d11s.ts`.
Les droits restent ceux de leurs auteurs, sous les termes de la licence MIT.
